// how it works

Up in under
ten minutes.

No firewall rules. No VPN. No port forwarding. Just a single .exe on the site machine.

01 —
🏢

Add your site

Log into the portal, give the site a name, set the local IP and port of your BAS or controller. Choose a subdomain — or use your own domain.

02 —
⬇️

Download the client

Portal generates a pre-configured bypass-client.exe with your token baked in. Copy it to the site PC — one file, no dependencies.

03 —
⚙️

Install as a service

Run the installer — it registers as a Windows service and starts automatically on boot. Done. The site shows Online in your portal.

04 —
🌐

Access from anywhere

Open a browser, navigate to your subdomain. Full HTTPS, WebSockets working, live BAS data streaming — through any corporate firewall on port 443.

// features

Everything a contractor
actually needs.

No bloat. No cloud lock-in. Built specifically for BAS and trades workflows.

🔒

Port 443 only

All traffic over HTTPS. Works through corporate firewalls, hotel WiFi, cellular — anywhere outbound 443 is allowed.

⚡

Native WebSocket support

Raw TCP tunneling — not an HTTP proxy. Mango live data, alarm subscriptions, and dashboard updates work without any hacks.

🏷️

Your domain, your brand

Pro accounts use their own domain. krp.dhcautomation.ca stays krp.dhcautomation.ca. Clients never see BypassHQ.

📦

Single .exe client

No .NET runtime. No installer prerequisites. One file, copies over RDP or USB, runs on Windows 10/11 and Windows Server.

🔀

Multiple tunnels per site

One client exposes your BAS controller, camera NVR, and PLC simultaneously. Different subdomains, one connection.

🌐

Portal dashboard

See all sites, online/offline status, last-seen timestamps. Generate new tokens, download updated installers, manage teams.

🔄

Auto-reconnect

Client reconnects silently on network drops with exponential backoff. Site comes back online automatically — no site visits required.

🏗️

Self-hosted option

Run BypassHQ on your own VPS. Docker Compose deployment, HAProxy + Caddy included. Full control over your infrastructure.

🔗

SlateBAS integration

Native integration with SlateBAS — tunnel status visible directly in your BAS dashboard. Coming Q3 2026.
